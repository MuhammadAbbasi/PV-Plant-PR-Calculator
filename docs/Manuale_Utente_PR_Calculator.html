📘 Manuale Utente & Guida Operativa

Software: PR Calculator v15.0 · Cliente: GET SRL · Impianto: Mazara 01 (12.62 MWp)

v15.0 Final Release

📌 Scopo del Software

Il software PR Calculator v15.0 automatizza il ricalcolo del Performance Ratio (PR) giornaliero e mensile, corregge ed interpola le anomalie dei contatori fisici SATAC, compensa le perdite di rete e di curtailment, converte i file telemetrici dal portale meteocontrol VCOM, e aggiorna in tempo reale il File Madre Excel 00 PR_recalculation_AGOS.xlsx.

🖥️ Interfaccia Grafica (GUI) ed Aree Numerate

L'interfaccia utente è suddivisa in 9 aree funzionali principali per un utilizzo intuitivo ed esente da errori di imputazione.

Figura 1: Layout dell'interfaccia grafica con la numerazione dettagliata delle 9 aree operative.

📌 Dettaglio delle Aree dell'Interfaccia e Istruzioni d'Uso

1 Area Intestazione e Guida Rapida

Contiene il brand GET SRL, la versione del software e il pulsante di aiuto rapido [ ? Guida d'Uso ] che apre istantaneamente questo manuale nel browser.

2 Selezione Cartella di Input (SCADA / VCOM)

Permette all'operatore di selezionare la cartella dei file grezzi tramite il pulsante [ Sfoglia... ]:

  • Giorno Singolo: Selezionare la cartella del giorno specifico (es. 2026 08/19).
  • Modalità Mensile Batch: Selezionare la cartella del mese (es. 2026 08). Il software rileva automaticamente tutte le cartelle dei giorni (01...31) ed esegue il calcolo in sequenza automatica.

3 Parametri di Calcolo e Riferimento POA

Gestisce la configurazione dei parametri di calcolo delle perdite e del sensore di irraggiamento:

Parametro Descrizione e Funzione Valore Predefinito
Data (AAAA-MM-GG) Rilevata automaticamente dal nome della cartella o dai file Excel. Automatico (es. 2026-08-19)
PR Mensile PVSyst Obiettivo mensile teorico letto dalla tabella PVSyst con degradazione annua dello 0.4%. Auto-compilato
Irraggiamento Min (W/m²) Soglia minima per attivare i calcoli di perdita di energia per inverter. 50 W/m²
Riferimento POA Selezione del metodo di irraggiamento: Media (Average) (Standard IEC) o Conditional MAX (Tol. 10%). Media (Average)

4 Opzione Ricalcolo Forzato

Se la casella [ Ricalcola forzatamente i giorni già elaborati ] è attivata, il software ricalcola da zero tutti i giorni sovrascrivendo i file giornalieri esistenti. Se deselezionata, il software salta velocemente i giorni già elaborati.

5 Pulsanti di Azione e Sincronizzazione

Contiene i comandi principali dell'applicazione:

  • [ Calcola Performance Ratio ]: Avvia l'elaborazione completa del giorno o del mese batch.
  • [ Sync SCADA PR ]: Importa il PR SCADA dal report KPI nel File Madre.
  • [ Sync VCOM PR ]: Importa il PR dal file CSV VCOM nel File Madre.
  • [ Interrompi ]: Esegue un arresto sicuro al termine del giorno in corso.

6 Configurazione Sorgente Dati (SCADA / VCOM / Misto)

Consente all'operatore di scegliere la sorgente dei dati per il calcolo:

  • SCADA (Predefinito): Usa i file SCADA standard a 15 minuti.
  • VCOM: Forza l'uso dei file CSV VCOM per tutti i giorni.
  • Misto (SCADA + VCOM): Consente di specificare singolarmente i giorni da elaborare con dati VCOM (es. inserendo 19, 22, 23 nella casella o tramite la griglia interattiva).

7 Tabella Target PVSyst e Degradazione Annuale

Mostra i valori di Target PR contrattuali mensili degradati dello 0.4%/anno a partire dal COD (Febbraio 2025). Evidenzia automaticamente il mese della data selezionata.

8 Indicatore di Stato e Barra di Avanzamento

Mostra in tempo reale lo stato dell'elaborazione (es. "Elaborazione in corso: Giorno 19/31...") e segnala il completamento con successo.

9 Console Live Log di Esecuzione

Finestra di testo che riporta tutti i log dettagliati dell'operazione, la pulizia dei dati, le conversioni VCOM e la scrittura delle formule sul File Madre Excel.

💡 Casi d'Uso Operativi (Use Cases)

Caso d'Uso 1: Calcolo Mensile Standard da Dati SCADA (Routine Fine Mese)

Scenario: L'operatore deve ricalcolare l'intero mese di Agosto 2026 utilizzando i file SCADA ufficiali.

  1. Aprire l'applicazione dist/PR_Calculator_v15.exe.
  2. Cliccare su [ Sfoglia... ] (Area 2) e selezionare la cartella del mese 2026 08.
  3. Assicurarsi che la sorgente dati sia impostata su SCADA (Area 6).
  4. Cliccare sul pulsante principale [ Calcola Performance Ratio ] (Area 5).
  5. Risultato: Vengono generati i 31 file giornalieri PR_recalculation_DD_ago.xlsx e il File Madre 00 PR_recalculation_AGOS.xlsx viene popolato con le formule, le letture del contatore nella colonna Meter Reading [MWh] e i totali sulla Riga 36.

Caso d'Uso 2: Recupero di Giorni con SCADA Mancante tramite Dati VCOM

Scenario: Nel mese di Agosto 2026, i giorni 19, 22 e 23 non hanno i file SCADA ma dispongono delle esportazioni CSV VCOM.

  1. Selezionare la cartella del mese 2026 08.
  2. In Area 6, selezionare la sorgente Misto (SCADA + VCOM).
  3. Inserire nel campo Giorni VCOM la stringa 19, 22, 23 oppure cliccare [ Seleziona Giorni... ] per far scansionare automaticamente le cartelle vcom/.
  4. Cliccare su [ Calcola Performance Ratio ].
  5. Risultato: Il motore converte i CSV VCOM per i 3 giorni indicati, accumula le letture del contatore ($M_{\text{prev}} + E_{\text{today}}$), evidenzia le tre righe nel File Madre in Arancione Chiaro #FFE0B2 ed inserisce la nota esplicativa sulla differenza di circa 300 kW.

Caso d'Uso 3: Ricalcolo Forzato di un Singolo Giorno

Scenario: Un file SCADA del giorno 19 Agosto è stato scaricato nuovamente per correzione e si desidera ricalcolare solo quel giorno.

  1. Selezionare la cartella del giorno specifico 2026 08/19.
  2. Spuntare la casella [ Ricalcola forzatamente i giorni già elaborati ] (Area 4).
  3. Cliccare su [ Calcola Performance Ratio ].
  4. Risultato: Il giorno 19 viene ricalcolato da dati SCADA. Nel File Madre la riga torna di colore bianco e la nota VCOM viene rimossa automaticamente.

Caso d'Uso 4: Sincronizzazione dei PR Esterni (SCADA & VCOM)

Scenario: Aggiornare direttamente le colonne PR SCADA e PR VCOM nel File Madre.

  1. Cliccare su [ Sync SCADA PR ] per selezionare il report KPI_Report_Daily.xlsx e popolare la colonna PR SCADA.
  2. Cliccare su [ Sync VCOM PR ] per selezionare il report Performance_ratio_vcom.csv e popolare la colonna PR VCOM.
  3. Risultato: Il File Madre ricalcola istantaneamente tutte le disponibilità e si salva in sicurezza.
