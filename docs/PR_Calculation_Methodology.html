1. Introduction to PR Calculation1. Introduzione al calcolo del PR

Performance Ratio (PR) answers one question: "Of all the energy the plant could have produced given the sunlight it received, how much did it actually produce?" A PR of 100% would mean zero losses. Real plants sit below 100%; Mazara 01 typically runs around 82–83%.

Performance Ratio (PR) risponde a una domanda: "Di tutta l'energia che l'impianto avrebbe potuto produrre data la luce ricevuta, quanta ne ha effettivamente prodotta?" Un PR del 100% significherebbe zero perdite. Gli impianti reali stanno sotto il 100%; Mazara 01 si attesta intorno all'82–83%.

              Actual energy producedEnergia effettivamente prodotta
PR (%) =  ------------------------------------------  × 100
          Energy the sunlight could supportEnergia che la luce poteva sostenere
Why it matters: the operator has a contractual guarantee (Allegato 9.1) to keep PR above a yearly target; falling below triggers a penalty. The calculation must be transparent and repeatable. Perché conta: l'Operatore ha una garanzia contrattuale (Allegato 9.1) di mantenere il PR sopra un obiettivo annuo; scendere sotto attiva una penale. Il calcolo deve essere trasparente e ripetibile.

3. Core Formulae with Annotations3. Formule principali con annotazioni

3.1 Reference irradiance (Column I)3.1 Irraggiamento di riferimento (Colonna I)

Convert each 15-min irradiance reading to energy density:Converti ogni lettura di irraggiamento da 15 min in densità di energia:

kWh/m²  =  W/m²  ÷  4000        (÷1000 W→kW, ÷4 for 15 min)(÷1000 W→kW, ÷4 per 15 min)

Pick one reference from the two sensors (Conditional MAX, default):Scegli un riferimento tra i due sensori (MAX Condizionale, predefinito):

if both 0:            reference = 0
if exactly one 0:    reference = working sensor
if |P1−P3|/avg > 10%: reference = HIGHER sensor
else:                reference = average
gate: if reference×4000 < 50 W/m² → 0se entrambi 0:        riferimento = 0
se uno solo 0:        riferimento = sensore attivo
se |P1−P3|/media>10%: riferimento = sensore PIÙ ALTO
altrimenti:           riferimento = media
soglia: se rif×4000 < 50 W/m² → 0
A dirty/shaded sensor reads too low; trusting the higher one is conservative and avoids inflating PR. Σ I = daily sum of Column I (kWh/m²).Un sensore sporco/in ombra legge troppo basso; fidarsi del più alto è prudente ed evita di gonfiare il PR. Σ I = somma giornaliera della Colonna I (kWh/m²).

No double-counting: curtailment is booked only while the inverter actually produces. During a full outage the grid signal also reads ~0, but that energy is already the downtime loss — counting it twice pushed Compensated PR to an impossible 108% on 12 Jun 2026 before the fix.Niente doppio conteggio: la limitazione si registra solo mentre l'inverter produce davvero. Durante un fermo totale anche il segnale di rete legge ~0, ma quell'energia è già la perdita di fermo — conteggiarla due volte portò il PR Compensato a un impossibile 108% il 12 giu 2026 prima della correzione.

3.5 Compensated PR · 3.6 Per-inverter · 3.7 Availability · 3.8 Target3.5 PR Compensato · 3.6 Per inverter · 3.7 Disponibilità · 3.8 Target

Compensated PR = (Actual energy + Σ losses) / (12,625 × Σ I) × 100
Per-inverter PR = (inv_energy + inv_loss) / (DC_inv × Σ I) × 100
Availability    = E / (E + L1 + L2 + L3) × 100
Target(month,year) = PVSyst_base(month) × (1 − 0.4%)^n     (n = contract years since Feb 2025)PR Compensato  = (Energia eff. + Σ perdite) / (12.625 × Σ I) × 100
PR per inverter = (energia_inv + perdita_inv) / (DC_inv × Σ I) × 100
Disponibilità   = E / (E + L1 + L2 + L3) × 100
Target(mese,anno) = base_PVSyst(mese) × (1 − 0,4%)^n     (n = anni contrattuali da feb 2025)
Sanity rule: a correct Compensated PR cannot meaningfully exceed 100% — you cannot recover more than the sunlight could support.Regola di controllo: un PR Compensato corretto non può superare in modo significativo il 100% — non si può recuperare più di quanto la luce potesse sostenere.
